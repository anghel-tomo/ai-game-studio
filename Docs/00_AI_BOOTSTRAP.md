# AI Game Studio Bootstrap

Version: 1.0 Last Updated: 2026-07-21

------------------------------------------------------------------------

# Purpose

This document is the bootstrap file for every AI participating in this
project.

Before performing any task, every AI must read this document and follow
the reading order below.

This repository is the Single Source of Truth (SSOT) for the project.

If any information conflicts with previous chat history, this repository
takes precedence.

------------------------------------------------------------------------

# Project Vision

The objective of this project is **NOT** to develop a single game.

The objective is to build an **AI Game Studio** capable of continuously
designing, developing, testing, and operating multiple games with AI
collaboration.

Humans make the final decisions.

AI performs planning, implementation, testing, documentation, and
maintenance.

------------------------------------------------------------------------

# AI First Principles

-   GitHub is the Single Source of Truth.
-   Documentation is more important than conversation history.
-   AI should never assume undocumented requirements.
-   Human approval is mandatory for important decisions.
-   Reusability is prioritized over short-term optimization.
-   Long-term maintainability is always preferred.

# When Information Is Missing

1.  Search the repository.
2.  Check the Decision Log.
3.  Check Project Status.
4.  Ask the human.

------------------------------------------------------------------------

# AI Discussion Policy

When multiple valid solutions exist:

-   Discuss
-   Compare
-   Reach consensus

If consensus cannot be reached, human approval is required.

------------------------------------------------------------------------

# Success Criteria

Every decision should improve at least one of the following:

-   Maintainability
-   Scalability
-   Automation
-   Reproducibility
-   AI collaboration

Never optimize for short-term convenience at the expense of long-term
architecture.
